## 1. ¿Cuál de las tres formas es la más cómoda si tuvieras que cambiar el color del título en 10 páginas?
La mas comoda es la forma de archivo CSS externo. Al estar los estilos centralizados en un único archivo enlazado a las 10 páginas, solo tendrías que modificar una única línea de código en ese archivo para que el cambio se aplique de forma automática y simultánea en todo el sitio web.

## 2. ¿Por qué se desaconseja la primera forma?
Se desaconseja principalmente por si necesitaa cambiar un estilo, tendría que modifica manualmente elemento por elemento en todas las páginas y archivos, lo que consume mucho tiempo y aumenta la probabilidad de cometer errores
